# ravex-hire

## API Documentation (Swagger)

This project uses Swagger (OpenAPI) for API documentation.

### Viewing API Documentation

1.  Ensure the API application is running (e.g., via `docker-compose up api` or by running it locally, e.g., `npx nx serve api`).
2.  Open your browser and navigate to `http://localhost:<API_PORT>/api-docs` (replace `<API_PORT>` with the actual port, typically 3000).

### Generating `swagger-spec.json`

A static `swagger-spec.json` file can be generated by running a script. This is useful for sharing the API spec or for use with other OpenAPI tools.

**Prerequisites:**
*   The API application must be buildable and runnable locally.
*   Ensure `curl` is installed. `jq` is recommended for pretty-printing the JSON output.
*   If running outside Docker, ensure Node.js and project dependencies are installed.

**Steps:**
1.  Make sure the API application is built (e.g., `npx nx build api --prod`).
2.  Navigate to the API application directory: `cd apps/api`
3.  Run the generation script:
    ```bash
    ./generate-swagger-spec.sh
    ```
    (If you created a Node.js script, e.g., `node generate-swagger-spec.js`)
4.  This will attempt to start the API, fetch the Swagger JSON, save it as `apps/api/swagger-spec.json`, and then stop the API.
5.  If the script fails (especially with `npx nx serve api`), you might need to manually start the server, then run `curl http://localhost:3000/api-docs-json > apps/api/swagger-spec.json`, and then manually stop the server.

The generated `swagger-spec.json` can be found in the `apps/api` directory.
